# Wind rose asset

Generated by `npm run build:wind`.

- Script: `scripts/build-wind-roses.mjs` (shared binning in `scripts/wind-rose-build-lib.mjs`, mirrored in `src/lib/windRoseEpw.ts`).
- Source: hourly wind from climate.onebuilding.org TMYx EPW
- Record: each station uses its longest TMYx file (by `#years` in the EPW header) whose winter and annual calm pass the app's station sanity caps, trying the full-record `_TMYx.zip` first and the dated 15-year windows only when that is missing, unreadable or fails the caps.
- Stations: 875
- Failed: 0
- Output: `public/wind/australia-tmyx.json`
